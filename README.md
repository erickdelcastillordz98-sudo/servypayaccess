# 💸 ServyPayAccess

Sistema de pagos simulados con Node.js + Telegram Bot.

## 🚀 Funciones

- Registrar pagos simulados
- Aprobar pagos
- Calcular comisiones
- Consultar saldo (wallet)
- Integración con bot de Telegram

## 🧠 Tecnologías

- Node.js
- Express
- Telegram Bot API
- Railway (deploy)

## 📦 Endpoints

### Crear pago
POST /pago

### Consultar saldo
GET /saldo
